# Домашнее задание 3

Возьмите классы с практики и дополните их в одном `hw_classes_base.py`. Цель — выделять важные слова текста. Реализуйте `TfidfVectorizer` — наследника `CountVectorizer`, который вместо частот возвращает веса TF-IDF. Добавьте в него настройки `lowercase` и `use_idf`, метод класса `from_config()` и атрибут `idf` для чтения. Создайте класс `KeywordExtractor`, который хранит векторизатор и выбирает до `top_n` ключевых слов в каждом тексте. Соберите всё в одном файле с функцией `demo()`, которая включает три сценария проверки с выводом и комментариями.

## Описание

Классы в `hw_classes_base.py`:

- `CountVectorizer` — строит словарь по корпусу текстов и превращает тексты в матрицу частот слов; поддерживает перевод в нижний регистр (`lowercase`), биграммы (`ngram_size`), ручное задание словаря (`vocabulary`), сохранение в словарь (`to_dict`) и восстановление из него (`from_dict`)
- `BinaryVectorizer` — наследник `CountVectorizer`: вместо частот отмечает наличие слова в тексте (1 — есть, 0 — нет)
- `TfidfVectorizer` — наследник `CountVectorizer`: возвращает веса TF-IDF (или только TF при `use_idf=False`); создаётся через `from_config()` по словарю настроек, веса IDF доступны через атрибут `idf`
- `KeywordExtractor` — хранит векторизатор и выбирает в каждом тексте до `top_n` слов с наибольшими весами (при равных весах — по алфавиту)

Функция `demo()` запускает три сценария:

1. Веса TF-IDF на обучающем корпусе `TRAIN_CORPUS` и проверочном `CHECK_CORPUS`
2. Настройки `lowercase=False` и `use_idf=False`, повторное обучение векторизатора
3. Выбор ключевых слов при `top_n=2` и `top_n=1` и обработка недопустимого значения `top_n=0`
