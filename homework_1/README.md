# Домашнее задание 1

В папке находятся решения первого домашнего щалания по курсу Python Basic.

## Структура

```text
homework_1/
├── 1_task.py
├── 2_task.py
├── 3_task.py
├── 4_task.py
├── 5_task.py
└── README.md
```

## Описание

- `1_task.py` — работа с множествами
- `2_task.py` — работа со списками и словарями на примере поисковых запросов
- `3_task.py` — обработка данных о заказах
- `4_task.py` — анализ статистики магазина
- `5_task.py` — обработка отзывов и расчёт статистики по товарам

## Требования
Сторонние библиотеки не используются.

## Запуск

Для запуска задачи:

```bash
python 1_task.py
```

Для запуска другой задачи замените номер файла на нужный.

## Проверка

Для проверки оформления кода используется `flake8`:

```bash
flake8 
```
