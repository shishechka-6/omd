# Домашнее задание 2

В `Corp_Summary.csv` лежит выгрузка по сотрудникам: ФИО, департамент, команда, должность, оценка, оклад. Колонки разделены `;`. Напишите программу, которая читает файл и по выбранному в аргументах варианту готовит отчёт. На экран выводите так, как вам удобно читать. Варианты отчётов такие. Основная функция должна принимать на вход int - номер варианта. остальные параметры - по желанию: 1. Иерархия: для каждого департамента показать, какие команды в него входят. 2. Сводка по департаментам: название, сколько человек, минимальная и максимальная зарплата, средняя по каждому департаменту. 3. То же самое, что в "2", но записанное в csv-файл. Имя выходного файла можно захардкодить(например, константой в начале файла) или передавать опциональным параметром в эту же функцию. Чтение файла и каждый отчёт вынесите в отдельные функции.


## Структура

```text
homework_2/
├── funct_hw.py
└── README.md
```

## Описание

Программа читает файл `Corp_Summary.csv` (ФИО, департамент, отдел, должность, оценка, оклад; разделитель `;`) и строит отчёт по выбранному варианту.

Функции в `funct_hw.py`:

- `read_data` — чтение CSV-файла и приведение оценки и оклада к числам
- `hierarchy` — вариант 1: список команд в каждом департаменте
- `prepare` — группировка окладов по департаментам (используется в вариантах 2 и 3)
- `svodka` — вариант 2: сводка по департаментам (количество сотрудников, минимальный, максимальный и средний оклад) с выводом на экран
- `svodka_csv` — вариант 3: та же сводка, записанная в файл `svodka.csv` (имя можно передать параметром `output_file`)
- `variant` — основная функция: принимает номер варианта (`1`, `2` или `3`) и запускает нужный отчёт

## Требования

Сторонние библиотеки не используются, только встроенный модуль `csv`.

Файл `Corp_Summary.csv` должен лежать в той же папке, из которой запускается скрипт.

## Запуск

```bash
python funct_hw.py
```

Номер варианта задаётся в блоке `if __name__ == "__main__":` в конце файла:

```python
variant(3)
```

Чтобы получить другой отчёт, замените `3` на `1` или `2`.
